# Роса — сайт питомника растений

Одностраничный лендинг питомника растений «Роса»: каталог, галерея,
условия доставки, форма заявки. Прототип, собранный в рамках курса
по вайб-кодингу.

## Ссылка
https://staysy-cpu.github.io/Rosa-v2/

## Как открыть локально
1. Клонировать репозиторий: git clone https://github.com/Staysy-cpu/Rosa-v2.git
2. Открыть папку в VS Code
3. Установить расширение Live Server
4. Правый клик по index.html → Open with Live Server

## Технологии
HTML5, CSS3, ванильный JavaScript. Без фреймворков и сборщиков.

## Что реализовано
- Адаптивная вёрстка (1024 / 768 / 640 px)
- Каталог с карточками, галерея с лайтбоксом и свайпом
- Мобильное меню, попапы, cookie-баннер с настройками
- Оптимизация изображений: WebP, srcset, preload для hero
- Доступность: skip-link, aria-атрибуты, клавиатурная навигация

## В планах
- Реальная отправка формы заявок (Supabase)
- Многостраничность: каталог, страница товара

## Структура проекта
index.html — главная страница
css/styles.css — стили
js/script.js — скрипты
images/ — изображения
privacy/, consent/, offer/, cookies/ — юридические страницы
